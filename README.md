Student Result Management System

A beginner-friendly Python-based Stu
dent Result Management System that allows users to add, search, and display student results through a simple command-line interface.

The project accepts student details and marks of five subjects, then automatically calculates the total marks, percentage, grade, and pass/fail status. All student records are stored in an Excel file using the openpyxl library, making result management simple, organized, and efficient.

Features

Add student results
Calculate total, percentage, grade, and status automatically
Search student results using roll number
Display all student records
Store data in an Excel file
Menu-driven command-line interface

Technologies Used

Python
Pydroid 3
openpyxl
Microsoft Excel

Project Purpose

This project was developed to practice Python concepts such as functions, loops, conditional statements, lists, file handling, and Excel file management.
